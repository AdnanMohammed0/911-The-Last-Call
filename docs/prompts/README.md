# البرومبتات — Prompts

كل عضو عنده ملف برومبت خاص. الملف يعرّف الذكاء الاصطناعي على دور العضو ومهامه، ويخليه يسجّل التقدم تلقائياً بملف العضو، وهذا الملف يقرأه الموقع.

| العضو | الملف | الدور | عدد المهام |
| :--- | :--- | :--- | :---: |
| Adnan | [`adnan.md`](adnan.md) | الذكاء الاصطناعي، الشبكات، وجزء من اللعب | 37 |
| Ali Imad | [`ali.md`](ali.md) | الـ 3D، العالم، الفن، والواجهات | 24 |
| Mohamed | [`mohamed.md`](mohamed.md) | برمجة سهلة: البيانات، الأدوات، المحتوى، الأنظمة البسيطة | 23 |

## طريقة الاستخدام

1. افتح المشروع بأداة الذكاء الاصطناعي (Claude Code, Cursor…). الأداة تقرأ `docs/AGENTS.md` تلقائياً (عن طريق `.claude/CLAUDE.md` و `.cursor/rules/`).
2. الصق **برومبت بداية الجلسة** من ملفك.
3. الذكاء الاصطناعي يتعرّف عليك من `git config` (عن طريق `docs/scripts/whoami.py`)، ويقرأ مهامك وتقدمك، ويقترح المهمة الجاية.
4. اشتغل. **أول ما يخلص أي شغل، الـ AI يحدّث `docs/data/progress/<id>.json` ويسوي commit و push تلقائياً**، بدون ما تطلب.
5. التقدم يظهر بالموقع باسمك خلال دقائق.

> حتى لو الـ AI نسى: Claude Code عنده Stop hook يمنعه ينهي الجلسة قبل الرفع، و GitHub Action يسجّل أي push ما حدّث ملف التقدم باسم صاحبه. اكتب `done P1-04` برسالة الـ commit حتى تنحسب المهمة مكتملة.

> تأكد إن `git config user.email` بجهازك مطابق للإيميل المسجّل باسمك في `docs/data/team.json` (أو سجّل دخول `gh auth login`). غير هذا، الذكاء الاصطناعي راح يسألك منو أنت.

## برومبتات عامة (لأي عضو)

**بداية جلسة:**
```text
اقرأ docs/AGENTS.md وتعرّف عليّ، بعدين لخّصلي وين وصلت وشنو المهمة الجاية.
```

**فرض تحديث معيّن (اختياري):**
```text
المهمة <ID> صارت <progress|testing|done|blocked>. الملاحظة: <...>.
```

**إضافة فكرة:**
```text
عندي فكرة للعبة: <الفكرة>. سجّلها كـ Issue بعنوان [فكرة] مع label idea (أو بـ docs/data/ideas.json إذا gh مو متوفر).
```
