# البرومبتات — Prompts

كل عضو عنده ملف برومبت خاص. الملف يعرّف الذكاء الاصطناعي على دور العضو ومهامه، ويخليه يسجّل التقدم تلقائياً بملف العضو، وهذا الملف يقرأه الموقع.

## طريقة الاستخدام

1. افتح المشروع بأداة الذكاء الاصطناعي (Claude Code, Cursor…). الأداة تقرأ `AGENTS.md` / `CLAUDE.md` تلقائياً.
2. الصق **برومبت بداية الجلسة** من ملفك.
3. الذكاء الاصطناعي يتعرّف عليك من `git config` (عن طريق `scripts/whoami.py`)، ويقرأ مهامك وتقدمك، ويقترح المهمة الجاية.
4. اشتغل. **أول ما يخلص أي شغل، الـ AI يحدّث `data/progress/<id>.json` ويسوي commit و push تلقائياً**، بدون ما تطلب.
5. التقدم يظهر بالموقع باسمك خلال دقائق.

> حتى لو الـ AI نسى: Claude Code عنده Stop hook يمنعه ينهي الجلسة قبل الرفع، و GitHub Action يسجّل أي push ما حدّث ملف التقدم باسم صاحبه. اكتب `done P1-04` برسالة الـ commit حتى تنحسب المهمة مكتملة.

> تأكد إن `git config user.email` بجهازك مطابق للإيميل المسجّل باسمك في `data/team.json` (أو سجّل دخول `gh auth login`). غير هذا، الذكاء الاصطناعي راح يسألك منو أنت.

## برومبتات عامة (لأي عضو)

**بداية جلسة:**
```text
اقرأ AGENTS.md وتعرّف عليّ، بعدين لخّصلي وين وصلت وشنو المهمة الجاية.
```

**فرض تحديث معيّن (اختياري):**
```text
المهمة <ID> صارت <progress|testing|done|blocked>. الملاحظة: <...>.
```

**إضافة فكرة:**
```text
عندي فكرة للعبة: <الفكرة>. سجّلها كـ Issue بعنوان [فكرة] مع label idea (أو بـ data/ideas.json إذا gh مو متوفر).
```
